\begin{frame}[label=slide1]{A code can protect information and implement a gate}
\talktext

\begin{block}{The construction}
48 physical qubits encode 3 logical qubits with distance 3.
A layer of $26\,T+22\,T^\dagger$ implements logical CCZ.
\end{block}
\begin{itemize}
\item A \emph{logical qubit} is one qubit encoded across a larger block.
\item Distance 3 permits correction of an arbitrary single-qubit error.
\item A \emph{transversal} layer acts separately on each physical qubit.
\end{itemize}
\takeaway{The code must satisfy both error-correction constraints and gate constraints.}

\note{Lead with the result. Logical means encoded, physical means the individual systems carrying the block. Single-qubit gates cannot spread a single gate fault across the block. No hardware performance improvement is claimed. CCZ will be defined on slide 5.}
\end{frame}

\begin{frame}[label=slide2]{Binary codes describe a quantum encoding}
\talktext

Let $S$ have independent stabilizer rows and $K$ have $k$ logical rows.
\[
\C_2=\operatorname{rowspan}(S)\subset\C_1=\operatorname{rowspan}\begin{bmatrix}K\\S\end{bmatrix}.
\]
A CSS code (Calderbank--Shor 1996, Steane 1996) has the orthonormal logical basis
\[
\ket{x}_L=\frac{1}{\sqrt{|\C_2|}}\sum_{v\in\C_2}\ket{xK\oplus v},\qquad x\in\F_2^k.
\]
Rows of $K$ are independent modulo $\C_2$.
\par\smallskip
$X$ flips a physical bit. $Z$ changes its sign when that bit is 1.
The $X$ checks come from $\C_2$; the $Z$ checks come from $\C_1^\perp$.
\takeaway{Logical basis states are equal superpositions over distinct classical cosets.}

\source{\refCS\par\refSt}
\note{Assume binary linear codes, introduce only the required quantum notation. Ket c is the computational basis vector labelled by the binary word c. The normalization follows from orthogonality of distinct words. Two nested codes specify this CSS code. Do not recite the stabilizer formalism beyond X flips and Z signs.}
\end{frame}

\begin{frame}[label=slide3]{The eight-qubit cube starts with affine functions}
\talktext

\begin{columns}[c,onlytextwidth]
\column{.40\textwidth}\centering\resizebox{.88\linewidth}{!}{\cubepicture{0}{0}{0}}
\column{.57\textwidth}
Physical positions: $u\in\F_2^3$.
\[
f_{x,b}(u)=b\oplus x_1u_1\oplus x_2u_2\oplus x_3u_3.
\]
The truth tables form $\RM(1,3)$, an $[8,4,4]$ binary code.
\par\medskip
Take $S=1$ and $K=(u_1,u_2,u_3)^{\!\top}$.
\end{columns}
\takeaway{The same cube supplies physical positions, generator rows, and a gate pattern.}

\note{The picture labels vertices by u and shows the parity truth table, not a noisy readout. The code is all affine truth tables. The constant row is the one stabilizer generator. The three coordinate rows will label three logical qubits. Keep the same example until slide 6.}
\end{frame}

\begin{frame}[label=slide4]{Complementary words encode three logical qubits}
\talktext

The classical code has 16 words, partitioned into 8 complementary pairs:
\[
\ket{x}_L=\frac{\ket{f_{x,0}}+\ket{f_{x,1}}}{\sqrt2},\qquad x\in\F_2^3.
\]
For example,
\[
\ket{000}_L=\frac{\ket{00000000}+\ket{11111111}}{\sqrt2}.
\]
The eight disjoint pairs give eight orthogonal states: $k=3$ logical qubits.
\par\medskip
Flipping all 8 bits exchanges the two words and leaves the encoded state unchanged.
\takeaway{A diagonal gate must assign the same phase to both words of each pair.}

\note{Explain relative phase on the pair: changing the sign of only one word leaves the encoding subspace. The logical gate is defined by the phase common to each pair. The all-X check is exactly the complement swap.}
\end{frame}

\begin{frame}[label=slide5]{Single-qubit phases can produce a three-qubit CCZ}
\talktext

\[
T=\operatorname{diag}(1,e^{i\pi/4}),\qquad T^\dagger=T^{-1}.
\]
Logical CCZ multiplies $\ket{111}_L$ by $-1$ and leaves the other 7 logical labels unchanged:
\[
\mathrm{CCZ}\ket{x}_L=(-1)^{x_1x_2x_3}\ket{x}_L.
\]
Choose $T^\dagger$ at parity-one vertices $p(u)=u_1\oplus u_2\oplus u_3$ and $T$ elsewhere.
\[
W(c)=\sum_u(-1)^{p(u)}c(u),\qquad \text{phase on }\ket{c}=e^{i\pi W(c)/4}.
\]

\note{T is a phase rotation on physical basis bit 1. Define CCZ before using its resource implications. W is an ordinary integer sum, unlike Boolean XOR. There are four gates of each sign in the cube. Every physical site contributes independently.}
\end{frame}

\begin{frame}[label=slide6]{The toy gate works, but its distance is two}
\talktext

Since $W(c)=d_H(p,c)-4$,
\[
\begin{array}{c|c|c}
\text{logical label}&W(f_{x,0}),\ W(f_{x,1})&\text{phase}\\\hline
x\ne111&0,\ 0&+1\\
x=111&-4,\ +4&-1
\end{array}
\]
Both words in each pair acquire the required phase.
\par\medskip
Two physical $Z$ errors commute with the all-$X$ check and can change a logical sign.
Thus the cube code (Campbell--Howard 2017) has parameters $\qcode{8}{3}{2}$.
\takeaway{The 48-qubit construction keeps the phase mechanism and raises the distance to 3.}

\source{\refCH}
\note{For an affine function other than p and p+1, the Hamming distance to p is four. The two exceptional functions have distances zero and eight. Plus and minus four both produce phase minus one. The cube has dX four and dZ two. A single Z has odd parity syndrome, but two Zs can cancel; this explains why the toy is inadequate for the target.}
\end{frame}

\begin{frame}[label=slide7]{Overlap counts control weights of sums}
\talktext

For binary words $a,b$, their product $a\wedge b$ selects the common ones.
\[
\wt(a\oplus b)=\wt(a)+\wt(b)-2\wt(a\wedge b).
\]
For three words the inclusion--exclusion coefficients are $1,-2,4$:
\[
\begin{aligned}
W(a\oplus b\oplus c)={}&W(a)+W(b)+W(c)\\
&-2\bigl(W(a\wedge b)+W(a\wedge c)+W(b\wedge c)\bigr)\\
&+4W(a\wedge b\wedge c).
\end{aligned}
\]
\takeaway{The identity holds for ordinary or signed weights. Terms of order 4 vanish modulo 8.}

\note{Use the face/edge intuition from the cube, but avoid a second running example. Verify the identity at one physical position where all three bits are one: three minus six plus four equals one. Signed weights obey the same pointwise identity.}
\end{frame}

\begin{frame}[label=slide8]{The general gate condition is a signed-weight congruence}
\talktext

Write $\Gamma_j=+1$ for $T$ and $-1$ for $T^\dagger$; define
\[
W_\Gamma(c)=\sum_{j=1}^n\Gamma_jc_j.
\]
A physical gate layer implements logical CCZ exactly when
\[
W_\Gamma(xK\oplus yS)\equiv4x_1x_2x_3\pmod8
\]
for every $x\in\F_2^3$ and $y\in\F_2^s$.
\par\medskip
Dependence on $x$ produces the logical gate. Independence from $y$ preserves each stabilizer coset.
\takeaway{A gate-design question becomes an integer congruence on a binary code.}

\note{This is the quantum-to-classical bridge. Each summand in a logical coset must have the same phase, so y must disappear. Physical signs are unknowns, not the signs of stabilizer eigenvalues. A global phase is fixed by the zero word.}
\end{frame}

\begin{frame}[label=slide9]{Only single, pair, and triple overlaps are needed}
\talktext

For distinct generator rows $g_a,g_b,g_c$ of $G=[K;S]$:
\[
\begin{aligned}
W_\Gamma(g_a)&\equiv0\pmod8,\\
W_\Gamma(g_a\wedge g_b)&\equiv0\pmod4,\\
\wt(g_a\wedge g_b\wedge g_c)&\equiv
\begin{cases}1\pmod2,&\{g_a,g_b,g_c\}=\{K_1,K_2,K_3\},\\0\pmod2,&\text{otherwise.}\end{cases}
\end{aligned}
\]
\par\smallskip
The parity conditions alone (Campbell--Howard 2017) allow a diagonal Clifford correction: \emph{quasi-transversal} CCZ.
The signed congruences demand physical $T/T^\dagger$ alone.
\vfill\hfill\hyperlink{backup-ch}{\beamerbutton{All nine parity conditions}}
\source{\refCH}
\note{Derive the coefficients from the previous slide rather than reading a condition list. Minus two forces pair divisibility by four. Four times an odd logical triple supplies the CCZ sign. Gamma is odd, so signed and unsigned triple weights agree modulo two. Parity conditions are necessary for signed implementation but are not sufficient. Explain the term quasi-transversal on this slide only.}
\end{frame}


\begin{frame}[label=slidehistory1]{From magic-state distillation to triorthogonal codes}
\talktext
\begin{description}\setlength{\itemsep}{0pt}
\item[2005] Bravyi--Kitaev: distill non-Clifford resource states using ideal Clifford operations.
\item[2012] Bravyi--Haah: triorthogonal matrices give CSS codes with logical $T$ gates, allowing Clifford corrections.
\item[2017] Campbell--Howard: joint distillation and multiqubit gate synthesis, including CCZ.
\item[2022] Nezami--Haah: classify small triorthogonal codes with $n+k\le38$ through unital spaces and Reed--Muller indicators.
\end{description}
\takeaway{Our logical CCZ uses an odd logical triple, unlike the even distinct-triple overlaps of ordinary triorthogonal matrices.}
\source{\refBK\par\refBH\par\refCH\par\refNH}
\note{Prior work is part of the mechanism, not only a reference list. Bravyi-Kitaev motivates distilling a non-Clifford resource using trusted Clifford operations. Bravyi-Haah turns gate action into constraints on binary rows. Campbell-Howard develops multiqubit synthesis and distillation, supplying the parity constraints used here. Nezami-Haah supplies the unital-space and indicator route to finite classification. Their n+k bound is not our n<=38 result. The 2026 generalized classification will appear in the length comparison.}
\end{frame}

\begin{frame}[label=slidehistory2]{A triorthogonal matrix and a triorthogonal space differ}
\talktext
\begin{columns}[T,onlytextwidth]
\column{.48\textwidth}
\textbf{Matrix $G$ (Bravyi--Haah 2012)}
\[
\begin{aligned}
\wt(g_a\wedge g_b)&\equiv0\pmod2,\\
\wt(g_a\wedge g_b\wedge g_c)&\equiv0\pmod2.
\end{aligned}
\]
Indices are distinct. Odd-weight rows label logical $T$ outputs; even-weight rows give $X$ checks.
\column{.48\textwidth}
\textbf{Space $\mathcal H$ (Nezami--Haah 2022)}
\[
\sum_{j=1}^{L}u_jv_jw_j=0\pmod2
\]
for all $u,v,w\in\mathcal H\subseteq\F_2^L$, including repeated vectors.
\par\smallskip
\emph{Unital}: $\mathbf1_L\in\mathcal H$.
Every word in $\mathcal H$ has even weight.
\end{columns}
\par\medskip
Nezami--Haah classify parent spaces, then obtain codes by puncturing and deleting coordinates.
\source{\refBH\par\refNH}
\note{Do not identify the row span of an ordinary triorthogonal matrix with a triorthogonal space: odd rows violate the space definition when repeated three times. A space quantifies over every triple of vectors, not only distinct generator rows. Setting u=v=w proves even weight. Unital means the all-ones vector is present, so the ambient length is even. Puncturing a parent space produces odd logical rows in descendant T codes. The distinction explains why classifying spaces can organize many codes and why our CCZ odd logical triple needs generalized conditions.}
\end{frame}

\begin{frame}[label=slide10]{Geometry fixes the stabilizers before the search}
\talktext

\begin{enumerate}\setlength{\itemsep}{7pt}
\item Choose distinct nonzero columns for $S$: guarantee $d_Z\ge3$.
\item Choose an 8-divisible stabilizer code: every stabilizer weight is a multiple of 8.
\item Search the logical rows $K$, then test physical signs $\Gamma$.
\end{enumerate}
\par\medskip
8-divisibility enforces the stabilizer-only overlap parities.
The mixed and logical-row conditions remain to be solved.
\takeaway{The solver does not rediscover distance or the geometric stabilizer structure.}

\note{Separate design assumptions from necessary conditions. Eight-divisibility is our stabilizer construction choice, not the definition of generalized triorthogonality. The target is dZ at least three and the completed code has dX at least three too. Transition from abstract criteria to explicit geometry.}
\end{frame}

\begin{frame}[label=slide11]{Projectivity rules out weight-one and weight-two Z logicals}
\talktext

Let $\beta_j$ be column $j$ of $S$. A $Z$ error at site $j$ has syndrome $\beta_j$.
\[
\beta_j\ne0\quad\Longrightarrow\quad\text{every weight-one error is detected},
\]
\[
\beta_i\ne\beta_j\quad\Longrightarrow\quad\beta_i\oplus\beta_j\ne0.
\]
Thus distinct nonzero columns detect every weight-two $Z$ error.
\par\medskip
Over $\F_2$, those columns are points of $\PG(s-1,2)$.
\takeaway{$d_Z\ge3$ follows from the stabilizer support, independently of the logical labels.}

\note{Give the short proof. Classical coding theorists recognize the parity-check columns of a distance-three code. In CSS language S is the X check matrix, hence a Z syndrome. This is Z-distance, not a proof of gate-gadget performance or dX.}
\end{frame}

\begin{frame}[label=slide12]{The support is projective space minus a subspace}
\talktext

\[
\mathcal P=\PG(5,2)\setminus\PG(3,2),\qquad |\mathcal P|=63-15=48.
\]
Write $\beta=(u,w)\in\F_2^4\times\F_2^2$ and retain exactly $w\ne00$.
\begin{center}\resizebox{!}{23mm}{\blockpicture{0}}\end{center}
The 6 coordinate functions $u_1,\ldots,u_4,w_1,w_2$ generate $S$.
\takeaway{Three cosets, each with 16 positions, give a projective $[48,6]$ stabilizer code.}

\note{Recall a point in binary projective space is simply a nonzero vector. The removed subspace is a four-dimensional vector subspace, projective dimension three. The three remaining values of w give three cosets of F2 to the fourth. Dot positions are a coordinate display, not a physical layout.}
\end{frame}

\begin{frame}[label=slide13]{Hyperplane sections give the two nonzero weights}
\talktext

A stabilizer word is the evaluation of
\[
\ell(u,w)=\lambda\cdot u\oplus\mu\cdot w.
\]
\begin{itemize}\setlength{\itemsep}{7pt}
\item $\lambda\ne0$: balanced on each of 3 blocks, weight $3\cdot8=24$.
\item $\lambda=0$, $\mu\ne0$: one on 2 of the 3 blocks, weight $2\cdot16=32$.
\end{itemize}
\[
\wt(\ell)=|\mathcal P|-|\mathcal P\cap\{\ell=0\}|.
\]
Projective two-weight codes and their geometry: Calderbank--Kantor 1986.
\takeaway{Weights 24 and 32 are multiples of 8. Geometry supplies the divisibility.}
\source{\refCK}

\note{Show the two cases, which prove both rank six and eight-divisibility. All nonzero coordinate combinations have positive weight, so rows are independent. This is the classical coding-theory engine. The classification uniqueness of this support is useful but not needed for construction; reserve it for a question.}
\end{frame}

\begin{frame}[label=slide14]{SAT assigns three logical bits to each geometric point}
\talktext

Unknowns: the column labels $\alpha_j\in\F_2^3$ of $K$.
\[
3n=144\ \text{label bits},\qquad
7+6s+3\binom{s}{2}=88\ \text{parity constraints (not CNF clauses)}.
\]
\begin{itemize}
\item Stabilizer-only conditions already hold.
\item Distance constraints are absent because $S$ guarantees $d_Z\ge3$.
\item Remaining parity conditions include products of up to three label bits.
\item A compatible labeling is followed by a separate physical-sign feasibility test.
\end{itemize}

\begin{frame}[label=backup-signs]{The physical signs have a polynomial formula}
\talktext
Set $\Gamma_j=1-2\gamma_j$, where $\gamma_j\in\{0,1\}$ marks $T^\dagger$.
\[
\gamma\cdot c\equiv\frac{\wt(c)}2-2x_1x_2x_3\pmod4,
\qquad c=xK\oplus yS.
\]
The unknowns remain binary even though the congruence is modulo 4.
\[
\begin{aligned}
\gamma(u,w)&=u_3\oplus w_1Q_1(u)\oplus w_2Q_2(u),\\
Q_1&=u_1\oplus u_2\oplus u_3\oplus u_1u_3\oplus u_2u_3\oplus u_2u_4,\\
Q_2&=u_3\oplus u_4\oplus u_1u_2\oplus u_1u_4\oplus u_3u_4.
\end{aligned}
\]
The resulting 22 flips satisfy the phase condition on all $8\times64=512$ codewords.

\begin{frame}[label=backup-lower]{Why a Reed--Muller indicator appears}
\talktext
Over $\F_2$, the stabilizer conditions say
\[
\sum_{\beta\in\mathcal P}\beta_{i_1}\cdots\beta_{i_t}=0,\qquad 1\le t\le3.
\]
Let $c=\chi_{\mathcal P}+\epsilon\delta_0$, choosing $\epsilon$ so $\wt(c)$ is even.
The origin changes no positive-degree moment.
Then $c\perp\RM(3,s)$, hence
\[
c\in\RM(3,s)^\perp=\RM(s-4,s),\qquad n=\wt(c)-c(0).
\]
Rank reduction and low-weight Reed--Muller classifications (Nezami--Haah 2022) make the $n\le38$ search finite.

\end{frame}
